# Glosario

| Término | Significado |
|---|---|
| **Adelanto (de liquidación)** | Factura al proveedor de lo vendido hasta hoy de un lote en liquidación que aún tiene stock. |
| **Albarán** | Documento de entrega de la mercancía. *Vender y entregar* lo valida. |
| **Bruto** | Peso total en la báscula, con las cajas. |
| **Caducidad** | Fecha en que caduca un lote. Se pone en el lote; el producto dice cuántos días antes se avisa (*Aviso de caducidad*) o que no caduca (*Sin caducidad*). |
| **Caja / envase** | Producto que se cuenta y se cobra aparte. Su peso es la tara. |
| **Compensar** | Convertir el importe de las cajas devueltas en saldo a favor del cliente. |
| **Cuadro de mandos** | Parte derecha de la pantalla de inicio del Mostrador: ventas del día, mensajes, promociones y lotes que caducan. |
| **DeCA** | Documento de control del transporte de mercancía. |
| **Desechar** | Dar de baja kg estropeados de un lote. |
| **Dirección (resumen de)** | Menú *Tableros › Mercas › Dirección*: ventas, compras, mermas y deuda comparadas con otros periodos. Se puede recibir cada tarde por correo. |
| **Facturación firme** | Trato con el proveedor: se le paga todo lo recibido. |
| **Liquidación por venta** | Trato con el proveedor: se le paga lo vendido menos nuestro margen. |
| **Liquidar** | Factura final al proveedor de un lote en liquidación ya agotado. |
| **Lote** | Partida de un producto de una compra. Lleva número, proveedor, fecha y origen. |
| **Margen** | Porcentaje que nos quedamos en la liquidación por venta. |
| **Mostrador** | Aplicación táctil del puesto (F1–F6). |
| **Neto** | Bruto menos la tara: lo que se compra o se vende. |
| **Packing list** | Relación de palets y cajas de un pedido. |
| **Presupuesto** | Venta en preparación. Se guarda sola. |
| **Promoción (⭐)** | Producto marcado con la estrella: sale primero en la venta y en el cuadro de mandos mientras tenga stock. |
| **Saldo a favor** | Dinero del cliente pendiente de aplicar: cajas devueltas, anticipos o lo que sobra de un cobro. |
| **Tara** | Peso de las cajas: número de cajas × peso del tipo de caja. |
